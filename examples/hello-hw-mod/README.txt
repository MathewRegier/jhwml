Hello HWMod
-----------

Copy this whole folder into:

  Steam\steamapps\common\Happy Wheels\mods\hello-hw-mod\

Restart Happy Wheels. A small overlay in the corner shows session, tick, and death
events from window.HWMod.

Requires JHWML with the HWMod SDK (run the launcher once after this update).

Docs: https://mathewregier.github.io/jhwml/
Discord: https://discord.gg/XcZePBgDBJ
