# Install for players

1. Keep Steam running. Close Happy Wheels.
2. Run **JHWML - Mod Launcher**. If Windows blocks it, choose More info → Run anyway. If install fails, run as administrator.
3. Confirm it found the folder that contains `Happy Wheels.exe`.
4. Pick the mods you want, then install.
5. Launch Happy Wheels from Steam (or Play in the launcher).

Drop extra mods as folders into `Happy Wheels\mods\`. Each folder needs a `mod.json`. Restart the game to load them. You do not need the launcher again unless Steam overwrites the loader.

A Steam update or **Verify integrity of game files** can remove the loader. Run the launcher again after that.

If Happy Wheels itself gets a new version, wait for a new launcher. This framework is built for **1.99.2**.

Launcher self-updates download from [github.com/MathewRegier/jhwml](https://github.com/MathewRegier/jhwml).
